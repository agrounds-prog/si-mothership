# MATCH + PIXEL REVEAL Art Pack V1

This pack includes both **concept targets** and **implementation-ready art assets** for SI Mothership teacher views.

## Included

### 1) Concept mockups
Use these as visual targets while integrating layouts in GitHub.

- `concepts/match/match_creator_concept.png`
- `concepts/match/match_live_control_concept.png`
- `concepts/pixel_reveal/pixel_reveal_studio_concept.png`
- `concepts/pixel_reveal/pixel_reveal_ready_concept.png`

### 2) Implementation-ready assets
These are cleaner background and UI element files intended to be layered behind live HTML controls.

- `implementation/shared/panels/glow_card_frame.png`

## Suggested integration approach
- Use the concept mockups as the visual reference for spacing, hierarchy, and tone.
- Use the four background images as main backplates for the corresponding teacher views.
- Use the transparent emblem, button, and panel PNGs as layered decorative assets over live app UI.
- Keep all labels, numbers, and interactive controls in HTML/CSS rather than baking those into the images.

## Notes
- Backgrounds are 16:9 friendly.
- Branding, buttons, and panel files are intended to support transparent layering.
- File names are already implementation-friendly for GitHub use.
